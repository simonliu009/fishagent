# 智渔 Agent UI 设计令牌

这份令牌对应当前运营控制台，作为没有 Figma 文件时的前端视觉基线。控制台面向养殖场值班人员，优先保证状态扫描、风险识别和重复操作效率。

## 视觉基线

- 画布：`#EEF3F2`，用于降低长时间值守时的视觉疲劳。
- 内容面板：`#FFFFFF`，只用于明确的信息分组，不嵌套卡片。
- 主色：`#0F766E`，用于正常操作和可执行动作。
- 深色导航：`#0B3B3A`，用于品牌和运行环境信号。
- 信息色：`#2563EB`，用于调度、链接和辅助状态。
- 警告色：`#B45309`，用于待审批、待复核和人工任务。
- 错误色：`#B91C1C`，用于离线、失败和升级状态。
- 成功色：`#15803D`，用于在线、已完成和验证通过。

## 布局与交互

- 页面最大宽度为 `1440px`，桌面端使用两列主工作区，移动端在 `860px` 以下改为单列。
- 面板圆角统一为 `8px`，重复数据使用紧凑网格或表格，避免营销式大卡片。
- 主要操作使用文本加动作，状态使用颜色和短标签；焦点环保持可见，便于键盘操作。
- 顶部指标只展示池塘、活动事件、待复核和待审批四个值，避免把实时告警埋在装饰元素中。
- 事件轨迹固定最大高度并独立滚动，资产台账和审批队列保持可扫描的行密度。

## 状态语义

| 状态 | 含义 | 前端处理 |
| --- | --- | --- |
| ONLINE / COMPLETED | 正常或已完成 | 主色或成功色 |
| VERIFY_PENDING / WAITING_APPROVAL | 需要人确认 | 警告色，保留明确动作 |
| OFFLINE / UNAVAILABLE / FAILED | 数据源或任务失败 | 错误色，显示恢复入口 |
| ESCALATED | 已升级给人工 | 错误色，显示人工任务 |

若后续接入 Figma 文件，应优先将 Figma Variables 映射到这些语义令牌，而不是直接复制页面像素。

# 风险矩阵

| 等级 | 典型动作 | 默认行为 | 自动执行前置条件 |
| --- | --- | --- | --- |
| L0 | 查询水质、设备、视觉帧 | 自动允许 | 只读工具，不产生设备命令 |
| L1 | 低溶氧时开启单台增氧机 | 受控自动 | 新鲜 GOOD 读数、池塘阈值、设备能力/归属、目标未满足、幂等键 |
| L2 | 关闭水泵、批量设备、调整投喂 | 人工审批 | 审批通过后再次经过策略门和幂等检查 |
| L3 | 投药、排水、批量停机 | 只生成人工任务 | 系统永不直接生成确认设备命令 |

## 策略顺序

1. 校验 Agent 身份和请求角色。
2. 校验设备存在、所属池塘和能力。
3. 校验读数质量、采样时间和阈值。
4. 校验当前影子状态、冷却和目标是否已满足。
5. 校验风险和审批状态。
6. 校验业务幂等键。
7. 在同一保存边界记录提案、命令、策略结果和 Outbox 事件。

## 明确禁止

- 用户文本或图片中的指令不能提升风险权限。
- Agent 不能直接调用设备网关写接口。
- 过期、缺失或不可用的视觉帧不能生成正常/异常结论。
- 重复审批、重复读数和重复 Celery 投递不能产生第二个业务效果。
